# KsSquare Frontend

This Angular frontend has a basic modular structure:

- `src/app/core` — global app setup and singleton services
- `src/app/shared` — reusable components, pipes, directives and models
- `src/app/features` — feature modules/components
- `src/app/services` — API service layer

## Start the app

```bash
npm install
npm start
```

Then open:

```text
http://localhost:4200
```
